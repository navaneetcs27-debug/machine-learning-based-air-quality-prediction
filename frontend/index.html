1. Project Title & Scope

Title: AeroAI: Machine Learning-Based Multi-Pollutant Air Quality Index (AQI) Prediction and Atmospheric Risk Modeling for Indian Megacities
Domain: Machine Learning, Environmental Informatics, Time-Series Regression

2. Work Completed in Phase 1 vs Progress in Phase 2

Phase 1 (Completed Prior) Phase 2 (Completed for Current Evaluation)
• Problem formulation & literature review on Indian AQI standards. • CPCB NAQI Multi-city dataset generated & validated (7,000 observations).
• Selection of 9 input parameters (PM2.5, PM10, NO2, SO2, CO, O3, Temp, Humidity, Wind). • Multi-model training: Gradient Boosting (R²=0.9996), Random Forest (R²=0.9995), Decision Tree (R²=0.9995), Linear Baseline.
• High-level theoretical architecture design. • Integrated New Delhi CAAQM station registry (Anand Vihar, ITO, RK Puram, Punjabi Bagh, Rohini, Lodhi Road).
• Baseline requirements gathering. • Real-time interactive UI prototype with animated SVG gauge, dual-sync sliders, and policy simulator.

4. Future Work for Phase 3 (Post Evaluation)

  • Hardware Integration: Interfacing physical particulate sensors (Plantower PMS5003) and electrochemical gas sensors (MQ-135) via ESP32 microcontrollers.
  • Edge ML Deployment: Model quantization via TensorFlow Lite / ONNX for direct embedded edge inference.
  • Alert Dispatch: Automated SMS and mobile app push notifications when Delhi NCR crosses GRAP Stage III/IV thresholds.
