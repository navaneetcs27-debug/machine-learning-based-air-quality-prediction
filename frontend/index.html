1. Project Summary

This project implements an end-to-end Machine Learning pipeline to predict continuous Air Quality Index (AQI) values under the official Central Pollution Control Board (CPCB) National Air Quality Index (NAQI) standard of India. Special focus has been given to the New Delhi NCR airshed.

2. Work Completed in Phase 1 vs Progress in Phase 2
Phase-1 (Completed Prior) Phase-2 (Current Review Work)
• Literature survey of CPCB guidelines & NAAQS standards. • Dataset formulation with 7,000 observations calibrated to CAAQM stations.
• Selection of 9 input parameters (PM2.5, PM10, NO2, SO2, CO, O3, Temp, Humidity, Wind). • Implemented official CPCB piecewise sub-index mathematical engine.
• Theoretical system architecture design. • Trained 4 ML models: Gradient Boosting (R²=0.9996), Random Forest (R²=0.9995), Decision Tree, Linear Baseline.
• Basic wireframing. • Developed functional real-time web portal with Delhi CAAQM station telemetry & policy simulator.
